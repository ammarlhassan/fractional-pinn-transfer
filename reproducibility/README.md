## How Results Were Generated

### Environment
- Python 3.10+, PyTorch 2.0+ (CUDA)
- Full dependencies: `requirements.txt` in project root
- Hardware: NVIDIA GPUs (experiments run on cuda:1, cuda:2, cuda:4, cuda:5)

### Configuration
All experiments use the **same** hyperparameters from `mf_fpinn/experiments/fdr_configs.py`:

| Parameter | Value |
|-----------|-------|
| lr (Vanilla / Phase 1) | 5e-4 |
| lr (Phase 2) | 1e-4 |
| weight_decay | 1e-5 |
| Architecture | 5 layers × 128 neurons, tanh |
| Fourier features | 64, σ=5.0 |
| Vanilla epochs | 25,000 |
| Phase 1 epochs | 5,000 + 50 L-BFGS |
| Phase 2 epochs | 20,000 |
| w_data / w_pde / w_bc / w_ic | 10 / 1 / 1 / 1 |
| pde_ramp_epochs | 3,000 |
| grad_clip | 5.0 |
| GL discretization | h=0.01, N_memory=100 |

### Reproducing All Experiments

The canonical rerun script:
```bash
# All 4 GPU batches (can run in parallel on separate GPUs)
python3 scripts/experiments/rerun_all_v2.py --gpu-batch 0 --device cuda:1
python3 scripts/experiments/rerun_all_v2.py --gpu-batch 1 --device cuda:2
python3 scripts/experiments/rerun_all_v2.py --gpu-batch 2 --device cuda:4
python3 scripts/experiments/rerun_all_v2.py --gpu-batch 3 --device cuda:5
```

Batch contents:
- **Batch 0**: Fidelity sweeps (α=0.5, α=1.0), 10 seeds each
- **Batch 1**: N_col budget (α=0.5, α=0.7), 10 seeds each
- **Batch 2**: N_col budget (α=1.0), Noise robustness, BVTT decomposition
- **Batch 3**: GL memory ablation

Output: `results/rerun/*.json`

**NOTE**: The composite comparison in batch 3 of rerun_all_v2.py contains a bug
(uses an inline dummy model, not the real Meng-Karniadakis architecture).
The composite section was removed from the paper. Composite results are
excluded from this reproducibility package.

### Reference Solutions

Ground truth solutions in `data/references/`:
- `reference_alpha{0.3..1.0}.npz` — 1D FDR, Laplace-domain inversion (Valsa-Brancik, N_terms=30, precision=30)
- `reference_2d_alpha{0.5,1.0}.npz` — 2D FDR, Fourier-Laplace inversion
- `burgers_reference_alpha{0.5,0.7,1.0}.npz` — Fractional Burgers, spectral method

Generated by `mf_fpinn/solvers/fdr_solver.py` (1D), `mf_fpinn/solvers/fdr_solver_2d.py` (2D).

### Low-Fidelity Data

LF data is generated on-the-fly by `generate_low_fidelity_data()` in `fdr_solver.py`
with degraded parameters (N_terms=12, precision=20) vs. HF (N_terms=30, precision=30).
This produces ~17% L2 error at α=0.5 — genuine multi-fidelity, not subsampled HF.

### JSON Format

Each result JSON contains:
```json
{
  "experiment": "description",
  "alpha": 0.5,
  "config": { ... },
  "results": {
    "vanilla": { "seeds": [...], "mean": X, "std": Y },
    "mf":      { "seeds": [...], "mean": X, "std": Y }
  }
}
```

All L2 errors are stored as **fractions** (0.05 = 5%). Paper tables display percentages.
Standard deviations use ddof=1 (sample std).

## Known Issues

1. **Composite NN section removed**: `rerun_all_v2.py` batch 3 defines an inline
   `CompositeMFNet` that is a trivial 2-scalar weighted average (500 training steps).
   The real architecture (`mf_fpinn/models/composite_nn.py`) uses the Meng-Karniadakis
   3-part design (NN_L + NN_lin + NN_nl, 25K epochs). The inline version produces
   73% L2 error. The section was removed rather than rerun.

2. **α=0.7 data pending**: `ncol_alpha0.7_nterms12.json` was still being generated
   at package creation time. When complete, copy from `results/rerun/` to `data/core/`.
